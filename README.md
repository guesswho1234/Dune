# Dune

**Dune** is a small Rust web app offering Price Forward Curve (PFC) machinery, specificyally for power market data. Users provide data and Dune constructs an arbitrage-free forward price curve. 

The web app offers example request data for each endpoint. Some of them are already valid as-is, others may need additional data points.

Access without a registered API-key is very limited. API-keys can be requested via E-Mail.

[Dune Web App](https://dune.sbcb.at/)
